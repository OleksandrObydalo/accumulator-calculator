# Калькулятор автономності акумулятора

Веб-додаток для розрахунку часу роботи від акумулятора через інвертор.

## Функції

- Розрахунок часу роботи для різних навантажень
- Підтримка різних типів акумуляторів (LiFePO4, Li-ion, AGM, GEL)
- Врахування ККД інвертора та його самоспоживання
- Врахування глибини розряду (DoD)
- Візуалізація енергетичного балансу
- Персоналізовані рекомендації

## Встановлення

```bash
npm install
```

## Запуск

```bash
npm run dev
```

Додаток буде доступний за адресою `http://localhost:5173`

## Збірка для продакшну

```bash
npm run build
```

## Деплой на GitHub Pages

Проект автоматично деплоїться на GitHub Pages при кожному push в гілку `master` або `main` через GitHub Actions.

### Налаштування GitHub Pages

1. Перейдіть в Settings → Pages вашого репозиторію
2. У розділі "Build and deployment":
   - **Source**: виберіть "GitHub Actions"
   - Збережіть налаштування

### Локальна перевірка збірки

Для перевірки збірки локально з правильним base path:

```bash
npm run build
npm run preview
```
